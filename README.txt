# Aviation Center SGC v1.1 — Offline

Arquivos:
- index.html
- style.css
- app.js
- manifest.json
- sw.js

Uso:
1. Coloque os 5 arquivos na mesma pasta.
2. No GitHub Pages, abra o site uma vez com internet e adicione à Tela de Início do iPad; depois o Service Worker permite o carregamento offline.
3. O sistema também usa localStorage para manter os dados no dispositivo.
4. Use Backup > Exportar backup JSON regularmente.
5. Imprimir / gerar PDF cria exatamente 4 páginas A4, separadas pelo SGC.

Observação:
O modelo foi estruturado a partir do PDF principal de 4 páginas enviado pelo usuário. As tabelas e pontos de teste foram transcritos do documento; campos de "valor encontrado" ficam editáveis.

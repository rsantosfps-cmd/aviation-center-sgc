Aviation Center Calibrações
Versão de desenvolvimento visual: 1.3.3

Esta versão aplica ao sistema o padrão visual inspirado nas telas de referência fornecidas:
- tema escuro profissional em azul/naval;
- dashboard com cartões de acesso rápido;
- painel lateral de navegação;
- área de status e validade;
- visual responsivo para iPad, celular e notebook.

Nome exibido do sistema: Aviation Center Calibrações

A lógica dos laudos e o armazenamento local foram preservados. A validade padrão permanece 2 anos.
A impressão continua usando Letter e o modelo de impressão próprio.
